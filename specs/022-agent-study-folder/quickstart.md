# Quickstart: validate the journey

1. `pnpm check`, `pnpm test`, `pnpm e2e` (AGENTS.md).
2. With the simulated Drive (dev stack), follow the two e2e journeys: connected, and not connected.
3. With a real model and a real Drive, in English and French, run the table of [the journey](../../docs/agent-journeys/05-study-folder.md#how-we-verify-it).
4. Check the conversation's cost after the consent and after Apply, and that no file name appears in the answers.
