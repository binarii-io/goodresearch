# Quickstart: validate the journey

1. `pnpm check`, `pnpm test`, `pnpm e2e` (see AGENTS.md).
2. With a real model, in English and French, run the table of [the journey](../../docs/agent-journeys/04-create-study.md#how-we-verify-it).
3. On the team's Studies page, create a study with a name only, then one with a goal: each opens, and is listed in no project.
4. Check that the conversation's cost grows after Apply.
