# @goodresearch/api-client

TanStack Query client generated by [orval](https://orval.dev) from `openapi.json` (itself generated from the API). Never edit `src/generated/`.

```bash
pnpm --filter @goodresearch/api-client generate   # export OpenAPI from the API, then regenerate
```

`src/fetcher.ts` sends same-origin cookies and turns problem details into `ApiError` (`status`, `code`).
