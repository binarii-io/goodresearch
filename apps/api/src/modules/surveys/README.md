# surveys

The responses of survey studies (spec 028, ADR-0011) and their analysis (spec 029, ADR-0012), context map #12 Surveys.

- **Responses** (`commands/survey-commands.ts`, `queries/response-queries.ts`): read from the form service with the person's access, stored as a copy (`surveys_responses`), never who answered nor the contact item. States (`refused-consent`, `profile-not-answered`, `out-of-target`, `counted`) are computed at each read by `stateSql`, the SQL twin of `domain/responses.ts` `stateOf`; the target rule (`surveys_target_rules`) never deletes a response.
- **Figures** (`queries/figure-queries.ts`, spec 029): counts per value of every item, and per value of one profiling item for a cross, in two grouped SQL queries over the counted responses; `domain/figures.ts` computes shares over respondents, mean, median, shares of agreement and disagreement, the small base (under 30) and hides shares under 5. Never stored: a reading or a rule change moves them at once. `figures(refs)` gives today's value a survey fact cites, one read per cross. `figuresText` is what the assistant reads.
- **Themes of open answers** (`commands/theme-commands.ts`, `queries/theme-queries.ts`, `domain/themes.ts`): the counted answers of one open item, masked by `maskAnswer` (`@goodresearch/shared`), numbered per run and sent in parts of 150 (queue `surveys.themes`, one run per study, never retried); with several parts, one last call merges the themes by their labels. `checkThemes` keeps an answer only if it was sent, a quote only if found word for word in it, drops themes without an answer and those rejected before; an answer belongs to one theme of its item: a later run never takes it from a live theme, but takes it from a rejected one, and a new theme left without answers is not kept. A theme's share counts only answers of counted responses. A person accepts, edits (the other language translated by `surveys.translate`), rejects, merges (at the versions read), moves a counted answer. Screens show the masked text, as sent.
- Ledger: tasks `survey-themes`, `survey-themes-merge`, `survey-themes-translation`; refs `survey-themes:<runId>:<part>` and `survey-themes-translation:<studyId>`; the Analysis tab shows their total with the survey facts' translations and their "Find facts" calls (`survey-facts:<studyId>`, Evidence's). `forFinding` (theme queries) gives Evidence what "Find facts" sends: the flat sort as `figuresText` and the accepted themes with their share.
- Tables: `surveys_responses`, `surveys_readings`, `surveys_target_rules`, `surveys_item_wordings` (`0056`), `surveys_themes`, `surveys_theme_answers`, `surveys_theme_runs` (`0057`); cascade with the study.
